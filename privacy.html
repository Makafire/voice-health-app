Политика конфиденциальности

Последнее обновление: 02.05.2026

1. Сбор данных

Приложение «Анализатор голоса» не собирает никакие персональные данные пользователей.

2. Аудиоданные

Запись аудио производится исключительно локально на устройстве. Аудиоданные не сохраняются и не передаются на серверы.

3. Хранение данных

История анализов хранится только в локальном хранилище браузера (localStorage) и может быть удалена пользователем.

4. Разрешения

Приложение запрашивает только разрешение на использование микрофона для записи голоса.
