# 🧬 Voice Health — Развлекательный анализатор голоса

**Версия:** 1.0.0
**Категория:** Развлечения
**Платформа:** PWA / Android (APK)

## 📱 Описание

Voice Health — это развлекательное приложение, которое анализирует ваш голос и даёт шуточные рекомендации: нужно ли вам поспать, размяться или перекусить.

### ⚠️ Важно!
**Приложение не является медицинским прибором!** Весь анализ является имитацией и носит исключительно развлекательный характер.

## 🚀 Быстрый старт

1. Откройте приложение в браузере
2. Нажмите на кнопку микрофона
3. Говорите что-нибудь 3 секунды
4. Получите весёлую рекомендацию!

## 🛠 Технологии

- Vanilla JavaScript (без фреймворков)
- Web Audio API (MediaRecorder)
- PWA (Service Worker + Manifest)
- Полностью офлайн-режим
- Локальная обработка (данные не отправляются на сервер)
